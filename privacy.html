ZIZ / SITE NOTES

Simple by design.

Last reviewed: October 2026. This is a personal portfolio featuring software experiments and links to public code projects. It doesn't offer accounts, collect form submissions or run advertising or analytics scripts in its own source.

What the website stores

The website stores your theme (light/dark) and motion preference in your own browser's local storage. The interactive 3D sculpture runs locally on your device. Saving a sculpture picture creates a file in your browser; the picture is not uploaded to this website.

External services

The site requests fonts from Google Fonts, which may receive your IP address and standard request information. GitHub Pages hosts the site, so GitHub's infrastructure may handle normal access logs under its own terms. Project links open github.com. No contact forms or newsletter subscriptions are operated here.

Names and creative works

“Ziz” is used as a personal nickname, not represented as a registered trade mark. Website artwork and code have their own applicable rights. Each open-source project has its own repository and licensing information, and third-party code retains its own terms. Nothing here claims ownership of other people's trade marks.

Questions

You can find the projects and their public source on GitHub. You can also review the website repository and suggest a correction there.
